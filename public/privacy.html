2. Qanday ma’lumotlarni yig‘amiz

Biz faqat platformani ishlatish uchun zarur bo‘lgan ma’lumotlarni yig‘amiz.

2.1. Siz taqdim etadigan ma’lumotlar

  • Hisob ma’lumotlari: telefon raqami (asosiy identifikator), to‘liq ism, ixtiyoriy username, parol (xeshlab saqlanadi).
  • Profil: avatar rasmi, fanlar, sinf/bosqich, o‘quv maqsadlari, onboarding sozlamalari.
  • Telegram bog‘lanishi: telefon tasdiqlash, parol tiklash va bildirishnomalar uchun Telegram foydalanuvchi/chat identifikatorlari.
  • Ta’lim faoliyati: olimpiada/test urinishlari, javoblar, ballar, reyting, sertifikatlar, amaliyot natijalari, kod yechimlari.
  • Tashkilot ma’lumotlari: o‘quv markazi nomi, manzil/hudud, a’zolik (o‘quvchi, o‘qituvchi, menejer, direktor), markaz rasmlari.
  • Ota-ona bog‘lanishi: ota-ona farzand hisobiga telefon orqali so‘rov yuboradi; farzand tasdiqlagach, progress ko‘rinadi (farzand telefoni ota-onaga qaytarilmaydi).
  • To‘lovlar: obuna reja, summa, to‘lov holati va provayder tranzaksiya ID (Click / Payme). Karta raqami bizning serverlarimizda saqlanmaydi.
  • Qo‘llab-quvvatlash: AI yordamchi va admin chat xabarlari.
  • 2FA (ixtiyoriy): TOTP maxfiy kaliti shifrlangan holda saqlanadi.

2.2. Avtomatik yig‘iladigan ma’lumotlar

  • Autentifikatsiya cookie’lari (JWT) va brauzer/ilova xotirasi (localStorage/sessionStorage) — sessiya, token va vaqtinchalik test holati.
  • Xavfsizlik loglari: muvaffaqiyatsiz login urinishlari, IP asosidagi himoya (brute-force oldini olish).
  • Texnik xatolik monitoringi (Sentry): qurilma/brauzer haqida cheklangan diagnostika ma’lumotlari.
  • Foydalanish metrikalar: streak, coin, faollik sanalari, analitika (admin/markaz panellari uchun agregat ko‘rsatkichlar).

2. Information we collect

We collect only what is needed to operate the platform.

2.1. Information you provide

  • Account data: phone number (primary identifier), full name, optional username, password (stored hashed).
  • Profile: avatar image, subjects, grade/level, learning goals, onboarding preferences.
  • Telegram linkage: Telegram user/chat IDs for phone verification, password reset, and notifications.
  • Learning activity: olympiad/test attempts, answers, scores, rankings, certificates, practice results, code submissions.
  • Organization data: education center details, memberships (student, teacher, manager, owner), center images.
  • Parent linking: a parent may request a link via the student’s phone; progress is shown only after student confirmation (the child’s phone is not returned to the parent in API responses).
  • Payments: subscription plan, amount, status, and provider transaction IDs (Click / Payme). We do not store full card numbers on our servers.
  • Support: AI assistant and admin support chat messages.
  • Optional 2FA: TOTP secrets stored encrypted.

2.2. Information collected automatically

  • Authentication cookies (JWT) and local/session storage for sessions, tokens, and temporary test state.
  • Security logs: failed login attempts and anti-abuse protections.
  • Error monitoring (Sentry): limited device/browser diagnostics.
  • Usage metrics: streaks, coins, activity dates, and aggregate analytics for admin/center dashboards.

3. How we use information

  • Create accounts, authenticate users by phone, and protect accounts.
  • Run olympiads/tests, leaderboards, certificates, and learning progress.
  • Provide dashboards and reports for centers, teachers, and parents.
  • Process premium subscriptions and payments.
  • Send OTP, reminders, and service notifications via Telegram.
  • Power AI features (question generation, PDF import, support chat, manager bot).
  • Security, fraud prevention, debugging, and service improvement.
  • Comply with legal obligations.

7. Security

  • Password hashing; JWT cookie auth; optional encrypted TOTP 2FA.
  • HTTPS, security headers, CSRF protection, rate limiting, admin brute-force protection.
  • Phone masking in logs; image upload validation.

No method of transmission over the Internet is 100% secure. Please report suspicious activity immediately.
